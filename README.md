# Werewolves Revenge SDK

Build your own maps for [Werewolves Revenge](https://store.steampowered.com/app/1867320/Werewolves_Revenge/)
in Unreal Engine 5.8.3. Other players can then play on your map via the
[Steam Workshop](https://steamcommunity.com/app/1867320/workshop/).

**[Download the latest SDK](https://github.com/DoingDylan/WerewolvesRevenge-SDK/releases/latest)**
· **[Read the guide](https://werewolvesrevenge.com/workshop)**

## What you need

- A Windows PC that can run Unreal Engine 5
- Unreal Engine 5.8.3, from the Epic Games Launcher
- Werewolves Revenge on Steam

## Get started

1. Download `WerewolfSDK_<version>.zip` from [Releases](https://github.com/DoingDylan/WerewolvesRevenge-SDK/releases/latest).
2. Extract it to a short path, for example `D:\WerewolfSDK_1.0.0`.
   Do not use Program Files or a OneDrive or Dropbox folder.
3. Open `WerewolfSDK.uproject`. The Werewolf SDK panel opens.
4. Press **+ New** to make your first map.

The full walkthrough is at **[werewolvesrevenge.com/workshop](https://werewolvesrevenge.com/workshop)**.

## Update to a new SDK

Each release is a separate download. Do not extract it over an old SDK.
Extract it into a new folder and copy your `WWMap_...` folders across.
See [Update the SDK](https://werewolvesrevenge.com/workshop/update-sdk).
